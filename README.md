This is a mod that allows you to add your own .ogg files, allowing you to add your own music into Minecraft. You can put the files into different folders to make radio stations, which are switchable by pressing the . and , keys. 

 

FAQ

What versions are supported?

Currently only Fabric 1.21.4 is supported, but I plan to support more versions soon.

How do I add music?

To add music, download some .ogg files that you want to add. Then, click on the 3 dots at the top of this instance. Click the Open folder button, then open the config folder. Then go into the mchorizonradio folder and make folders with your .ogg files.

 

How do I name the radio stations?

To name the radio stations, all you have to do is name the folders you make inside of the mchorizonradio folder be named what you want the radio station to be named.
